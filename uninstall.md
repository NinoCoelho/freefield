# Freefield Hybrid Uninstall Guide

This document describes how to completely remove everything installed by `setup-hybrid.sh`.

## Important: Modal Payment Requirement

**Modal's free tier now requires a payment method for GPU access.** If you didn't add one, the script falls back to local-only mode and no Modal resources are created. Check your Modal dashboard at https://modal.com/settings/billing to confirm.

---

## Quick Uninstall (Everything)

```bash
# 1. Stop any running processes
pkill -f "python main.py"                    # ComfyUI
pkill -f "comfy-api-proxy"                   # proxy
pkill -f "node.*server.ts"                   # Freefield server

# 2. Remove Modal deployment & secrets
modal app stop freefield                     # stop deployed app
modal app delete freefield                   # delete deployment
modal secret delete freefield                # delete gateway token secret
modal secret delete huggingface              # delete HF token secret (if you created it)
modal volume delete freefield-models         # delete model volume (~320 GB)
modal volume delete freefield-lab            # delete lab volume (if used)

# 3. Remove local ComfyUI & models
rm -rf ~/ComfyUI                             # ~5-10 GB + models (~325 GB)

# 4. Remove Freefield project (optional — keeps your code)
# rm -rf /Users/nino/Developer/freefield

# 5. Clean up .env
rm -f /Users/nino/Developer/freefield/.env
```

## Selective Uninstall

### Modal Backend Only

```bash
modal app stop freefield
modal app delete freefield
modal secret delete freefield
modal volume delete freefield-models
```

### Local ComfyUI Only

```bash
pkill -f "python main.py"
pkill -f "comfy-api-proxy"
rm -rf ~/ComfyUI
```

### Model Packs Only (keep ComfyUI)

```bash
# Remove specific pack models from local disk
rm -rf ~/ComfyUI/models/diffusion_models/*flux*
rm -rf ~/ComfyUI/models/diffusion_models/*ltx*
# ... or wipe all models
rm -rf ~/ComfyUI/models/*

# Remove from Modal volume (requires re-deploy to re-download)
modal volume delete freefield-models
```

### Freefield Config Only

```bash
rm -f /Users/nino/Developer/freefield/.env
```

## Verification After Uninstall

```bash
# Check Modal resources gone
modal app list | grep freefield        # should return nothing
modal secret list | grep -E "freefield|huggingface"  # should return nothing
modal volume list | grep freefield     # should return nothing

# Check local gone
ls ~/ComfyUI 2>/dev/null && echo "ComfyUI still exists" || echo "ComfyUI removed"
ls /Users/nino/Developer/freefield/.env 2>/dev/null && echo ".env still exists" || echo ".env removed"
```

## Reinstalling

Just run `./setup-hybrid.sh` again — it's idempotent for most steps.

- Modal: `modal deploy` creates new containers; volumes persist unless deleted
- Local: ComfyUI repo and models persist unless deleted
- `.env`: Regenerated by `setup_token.py`
